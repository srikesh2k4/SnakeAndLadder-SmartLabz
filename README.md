# Snake and Ladder

A simple, fully working Snake & Ladder game written in C# (.NET).  
Author: **Kotipalli Srikesh**

> Play from your terminal, support for 1–4 players, classic snakes and ladders, and deterministic or random dice.

---

## ✨ Features
- Classic 100-tile board with configurable snakes & ladders
- 1–4 players (human; easy to extend to bots)
- Random dice (1–6) or seeded dice for reproducible runs
- Clear turn-by-turn log and winner announcement
- Simple, testable architecture

---

## 🧰 Tech
- **.NET SDK** (7/8+)
- C# console application

---
